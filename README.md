# RtEED — Real-Time Employee Emotion Detection System

## About
A full-stack web application that detects employee emotions 
in real time using machine learning and live webcam input. 
Built with Django and Python.

## Features
- Real-time facial emotion detection via webcam
- ML classification with Accuracy and F1-Score reporting
- User registration, login and admin management
- Dataset upload and preprocessing pipeline
- Emotion prediction: Positive, Negative, Neutral

## Tech Stack
Python | Django | OpenCV | Scikit-learn | SQL | HTML/CSS

## Modules
- **User** — registration, login, dataset upload, predictions
- **Admin** — user activation, results monitoring
- **Data Preprocessing** — noise removal, missing data handling
- **Machine Learning** — 60/40 train-test split, emotion classification

## Dataset
CMU Multi-PIE Face Database — 750,000 images, 337 subjects, 
15 viewpoints, 19 illumination conditions

## Results
Successfully detects employee emotions in real time with high 
classification accuracy measured by F1-Score metrics.
